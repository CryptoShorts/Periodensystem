# Periodensystem
Interactive Periodic Table of Elements 

A fully interactive periodic table featuring all 118 elements, built with vanilla HTML, CSS, and JavaScript. Click any element for detailed info (atomic mass, electron configuration, melting/boiling points), filter by element category, or search by name, symbol, or atomic number. Dark-themed with color-coded element groups and a separate lanthanide/actinide series. No dependencies, no frameworks — single HTML file.
